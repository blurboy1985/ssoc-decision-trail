Which SSOC code does this job belong to?

Every job posting on MyCareersFuture carries a Singapore Standard Occupational Classification (SSOC) code. SSOC 2024 has 1,006 occupations, five levels deep, and it's easy to pick the wrong one. A Chef de Partie, for example, is filed under 51202 Senior cook, not 34341 Chef.

So I built SSOC Decision Trail:
1. Paste a job description or a MyCareersFuture link
2. Press Classify
3. Watch AI walk the SSOC tree level by level (major → sub-major → minor → unit → occupation), with every option it weighed and its probability on screen
4. Get one 5-digit code, and see why it won
